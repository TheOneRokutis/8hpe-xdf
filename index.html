Radumfang / Wheel Circumference

Value to code into the 8HP TCU for the fitted rear tyre size.

Value to enter
1942 mm
Prefer the tyre maker's published rolling circumference (Abrollumfang) when it is given — it already accounts for deflection under load. The 0.97 factor is the usual geometric → rolling conversion and is an approximation.

Formula

Geometric circumference = π × (rim_inch × 25.4 + 2 × width × profile / 100)

Program value = geometric × 0.97, rounded to a whole mm.

A tyre's true rolling radius is smaller than its geometric one because the sidewall deflects under load, so the rolling circumference is shorter than the geometric value. 0.97 is the conventional factor for that difference.

Accepted values

The transmission does not store an arbitrary number. It picks the closest entry from its fixed ratio list, so a value within roughly −1 % / +2.5 % of the reference is enough.

After you flash

  1. Flash the tune.
  2. Run Tool32 job steuern_lernfkt_ruecksetzen with argument 0.
  3. Drive above roughly 24 km/h for a minute or two so the adaptation can run.
  4. Read out status_lernfkt. The learned rear-axle value must equal the car's real diff ratio.
  5. If it is one step off (for example it learned 3.91 instead of 3.73), multiply the value you entered by real ratio / learned value, write the result, and repeat the reset and drive cycle.
This parameter is not for correcting the speedometer. Speedometer correction is done in the ABS/DSC coding, not here.
